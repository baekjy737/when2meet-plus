# QA 개선 구현 및 검증 기록

- 작업일: 2026-11-02
- 기준: main `e6b86f7`
- 브랜치: `feat/qa-feedback-improvements`
- 범위: QA 통합 기획의 모바일 입력, 생성 규칙, 응답 관리·수정 권한, 접근성·연속 결과 보기.

## 구현

- 기본 터치 스와이프는 페이지 스크롤, 탭은 한 칸 선택. 명시적인 `여러 칸 선택`에서만 드래그로 칠한다. 마우스·펜은 바로 드래그한다.
- 시간표는 실제 너비에 맞춰 날짜를 나눈다. 터치 칸은 최소 56×32px이며, 날짜 달력은 월별 7열을 유지한다. 저장 상태·도구·시간 머리글을 고정하고 내부 스크롤은 만들지 않는다.
- 화면 끝 자동 스크롤은 현재 편집 영역에 제한된다. 실제 터치 취소·두 손가락·너비 변경은 미완료 선택만 되돌린다. 터치에서 파생된 pointercancel은 별도로 처리한다.
- 두 모드 모두 새 일정의 과거 날짜를 선택한 기준 시간대로 검사한다. 15·30·60분 간격에 맞는 시작·종료 시각, 기준 시간대 변경, 잘못된 값 재선택 안내를 제공한다. 기존 과거 일정은 계속 조회·수정할 수 있다.
- 개인 전체 해제와 참여 취소, 관리자 응답 삭제·수정 권한 재발급을 제공한다. 필수 참석자 삭제 시 필터를 정리하고 최소 인원을 임의로 낮추지 않는다. 기존 TF 배분안은 다시 계산할 필요를 알린다.
- 첫 참여는 이름만으로 가능하다. 기존 응답은 저장된 기기 토큰·비밀번호·개인 수정 링크로 인증한다. 여러 기기를 유지하며 revision 충돌 시 자동 덮어쓰기를 중단한다.
- 개인 링크 재발급은 이전 링크만 만료시킨다. 관리자 복구는 모든 세션과 이전 링크를 만료시키며 비밀번호는 유지한다.
- 방향키·Enter/Space·Shift 범위 선택, 한국어 404, 일정별 제목, 기본 보안 헤더를 추가했다.
- 최적 결과에서 같은 참석자의 겹치거나 이어진 구간을 묶을 수 있다. XLSX·JSON은 화면과 같은 회의 길이·최소 인원·필수 참석자·병합·20개 제한을 적용한다. CSV는 전체 슬롯 자료다.

## 검증

- `node --import tsx --test src/lib/*.test.ts`: 52개 통과. 이전 DB 세션 일회 이전, 복구한 권한의 재시작 후 부활 방지, 다중 세션·수정 충돌·삭제 경합, 생성 시간대 경계, 분석·내보내기, 모바일 범위 계산을 포함한다.
- `npm run typecheck -- --incremental false`: 통과.
- `npm run build -- --webpack`: 실제 프로젝트 경로에서 최종 프로덕션 빌드 통과.
- 임시 DB와 실제 Chrome에서 320px·390px 생성 폼·날짜 페이지 유지·전체 해제·관리자 삭제·결과 강조 페이지 이동·JSON/XLSX 필터 일치를 확인했다.
- 별도 Chrome context로 개인 수정 링크, 기존 세션 유지, 두 기기 저장 충돌과 최신 응답 복귀, 관리자 복구 후 권한 만료, 본인 참여 취소와 삭제 후 늦은 저장 거부를 확인했다. 같은 탭에서 hash만 바뀌는 수정 링크와 불러오기 중 입력 차단도 검증했다.
- Chrome CDP 터치 입력으로 기본 스크롤, 칠하기, 마지막 칸 반영, touchcancel·두 손가락·너비 변경 롤백, 자동 스크롤 경계, 날짜 모드와 마우스·키보드 입력을 검증했다.
- iOS Safari·Android Chrome 실기기 검증은 아직 하지 않았다. 실기기에서 주소창·화면 회전·고정 머리글·자동 스크롤을 확인해야 한다.

## 배포 시 확인

- 기존 DB는 자동 이전된다. 배포 전 백업을 보관하고, 구버전 페이지를 열어 둔 사용자는 새로고침해 새 저장 방식을 적용한다.
- 기존 DB를 그대로 둔 구버전 서버 롤백은 새 권한 정책과 호환되지 않는다.
- 이 작업에서는 운영 DB·테스터 이벤트를 변경하지 않았으며 배포·main 머지도 하지 않는다.
- 이벤트 설정 변경·이벤트 자체 삭제·참가자 현지 시간대 변환은 후속 범위다.
