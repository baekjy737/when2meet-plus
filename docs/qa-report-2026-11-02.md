## 0. 접속 경로 (중요)
- KR 프록시(127.0.0.1:3130)로 `CONNECT latteclawbaek.taild8bc52.ts.net:8443` → **502** (tailscaled가 "lookup ... server misbehaving"). 이 주소는 은우님 tailnet(tail54314c)이 아니라 다른 tailnet(taild8bc52) 이름이라 박스의 tailscaled/DNS가 풀지 못함.
- 박스 직접 접속(DNS 198.18.0.1로 풀림) → TLS EOF로 실패.
- 공개 DNS(dns.google, KR 프록시 경유)로 확인하니 103.84.155.153 / .217 (Tailscale Funnel 공개 주소)였음. **KR 프록시(3130)로 해당 IP에 CONNECT**하고 SNI/인증서는 원래 호스트명으로 유지하는 로컬 중계(/workspace/when2meet-test/relay.py, 127.0.0.1:3131, 해당 호스트만 허용)를 만들어 브라우저를 그쪽으로 연결. 즉 **모든 트래픽은 KR 프록시 경유**, 직접 접속은 쓰지 않았다. Tailscale 설정은 건드리지 않았다. 중계는 테스트 후 종료.
- 인증서: Let's Encrypt, CN=latteclawbaek.taild8bc52.ts.net (유효). HTTP/2. 새 연결마다 응답이 느림(4~8초, KR 프록시 경로 영향으로 보임)이라 앱 자체 속도 평가는 못 했다.

## (b) UX 개선 제안
- 모바일 긴 격자: 칠하기 전용 "편집 모드" 토글, 또는 세로는 스크롤·가로 길게 눌러 칠하기로 분리. 칸 높이 18px(<44px 권장), 로그아웃 링크 52x23px, 달력 이전/다음 버튼 27x29px는 터치 대상이 작음. 값/버튼 글자는 15px, 시간·요일 라벨은 12px로 모바일에서 작은 편.
- 모바일 관리자 화면의 참가자/관리자 링크가 말줄임(…)으로 잘려 내용을 못 읽음(복사 버튼은 정상 동작: 복사됨 표시, 클립보드에 전체 URL 확인).
- 시간대: 표시는 항상 **이벤트 생성자 timezone 기준 그대로**이고(헤더에 "Asia/Seoul 기준" 작은 글씨) 보는 사람 시간대로 변환하지 않는다. LA 브라우저에서 KST 이벤트를 열어도 9:00 그대로, 날짜 하루 밀림 없음(좋음). 다만 다른 시간대에서 만든 이벤트는 생성자 timezone이 조용히 저장되고(LA 브라우저로 만들면 America/Los_Angeles) 선택 UI가 없다. 해외 체류 학생이 만들면 KST 학생들에게는 엉뚱한 시간으로 보임 → 생성 시 시간대 선택/표시, 참가자 화면에 "내 시간대로는 …" 보조 표기 권장.
- 결과 목록: 겹치는 슬라이딩 구간이 따로 나열됨(예: 10:00–11:00, 10:30–11:30, 11:30–12:30, 12:00–13:00). "연속 가능 구간으로 합치기" 옵션이 있으면 읽기 쉽다. 엑셀/CSV의 "최적 시간" 시트는 30분 단위 기본값이라 화면 기본(1시간)과 다르게 나옴.
- 비밀번호 칸에 "설정하면 다른 사람이 내 응답을 못 고칩니다" 안내 추가, 입장 후 내 응답 삭제 버튼 추가(아래 (c)/(e) 참고).
- 응답 삭제·이벤트 수정/삭제 UI가 없음: 로그아웃 버튼만 있고 "내 응답 삭제", 이벤트 제목·날짜 수정, 이벤트 삭제 기능이 없다(UI 번들에 PUT availability / POST participants / POST events / GET 외 요청 없음). 실수로 만든 이벤트·잘못된 이름 응답을 지울 수 없다.
- 날짜 조율 달력에서 응답 많은 날의 색 대비가 약함(2/8 칸이 거의 흰색).
